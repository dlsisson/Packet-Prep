Glossary

Key networking terms, explained simply.

A

ACL (Access Control List)
A set of rules that filters network traffic by permitting or denying packets based on criteria such as IP address or port.
ARP (Address Resolution Protocol)
Resolves a known IP address to its corresponding MAC address on a local network segment.

B

Bandwidth
The maximum rate of data transfer across a network path, usually measured in bits per second (Mbps, Gbps).
BGP (Border Gateway Protocol)
The routing protocol of the internet; used to exchange routes between autonomous systems (ISPs, large organizations).
Broadcast
A packet sent to all devices in a network segment simultaneously, addressed to the subnet's broadcast address.

C

CIDR (Classless Inter-Domain Routing)
A method of allocating IP addresses using prefix notation (e.g., 192.168.1.0/24) instead of fixed class boundaries.

D

Default Gateway
The router a host uses to send traffic destined for addresses outside its local subnet.
Default Route
A catch-all route (0.0.0.0/0) used when no more specific route matches a destination in the routing table.
DHCP (Dynamic Host Configuration Protocol)
Automatically assigns IP address, subnet mask, default gateway, and DNS server settings to network clients.
DNS (Domain Name System)
Translates human-readable hostnames (e.g., example.com) into IP addresses that routers can use.

E

Encapsulation
The process of wrapping data with protocol headers at each OSI layer as it travels down the stack before transmission.
Ethernet
The dominant wired LAN technology, defining framing, MAC addressing, and physical signaling over copper or fiber.

F

Firewall
A security device or software that monitors and controls incoming and outgoing traffic based on configured rules.
Frame
The Layer 2 PDU containing a payload, source MAC, destination MAC, and error-checking trailer.

H

HTTP / HTTPS (Hypertext Transfer Protocol / Secure)
Application-layer protocols for web traffic. HTTPS adds TLS encryption for confidentiality and data integrity.

I

ICMP (Internet Control Message Protocol)
Used for network diagnostics; carries messages like echo requests and replies (used by ping and traceroute).
IP Address (Internet Protocol Address)
A logical Layer 3 address (IPv4: 32-bit; IPv6: 128-bit) that uniquely identifies a device on a routed network.

L

LAN (Local Area Network)
A network confined to a single location such as a home, office, or campus, typically connected by Ethernet or Wi-Fi.

M

MAC Address (Media Access Control)
A 48-bit hardware address burned into a network interface card, used for Layer 2 frame delivery on a local segment.
MFA (Multi-Factor Authentication)
An authentication method requiring two or more verification factors, reducing the risk of compromised credentials.

N

NAT (Network Address Translation)
Maps private IP addresses to one or more public IP addresses, allowing many devices to share a single public IP.

O

OSI Model (Open Systems Interconnection)
A 7-layer reference framework (Physical, Data Link, Network, Transport, Session, Presentation, Application) for understanding network communication.
OSPF (Open Shortest Path First)
A link-state interior routing protocol that uses cost (based on bandwidth) to determine the best path within an autonomous system.

P

Packet
The Layer 3 PDU containing a payload, source IP, destination IP, and other header fields used for routing across networks.
PAN (Personal Area Network)
A very short-range network around a single person, typically using Bluetooth or USB to connect devices like phones and wearables.
Port
A 16-bit number used by TCP and UDP to identify a specific application or service on a host (e.g., port 443 for HTTPS).

R

Router
A Layer 3 device that forwards packets between different networks using routing tables and IP addresses.
Routing Table
A database on a router listing known networks, next-hop addresses, and metrics used to select the best path for forwarding packets.

S

SMTP (Simple Mail Transfer Protocol)
The application-layer protocol used to send email messages between mail servers and from clients to servers.
SSH (Secure Shell)
An encrypted protocol for securely accessing and managing remote devices over an unsecured network.
Subnet Mask
A 32-bit value that divides an IP address into network and host portions, determining which addresses belong to the same local network.
Switch
A Layer 2 device that forwards Ethernet frames between ports based on learned MAC address-to-port mappings.

T

TCP (Transmission Control Protocol)
A connection-oriented Layer 4 protocol providing reliable, ordered delivery with acknowledgments, sequencing, and retransmissions.
TLS (Transport Layer Security)
A cryptographic protocol that provides encrypted, authenticated communication over a network; successor to SSL.
Topology
The physical or logical arrangement of devices in a network; common types include star, bus, ring, and mesh.
Trunk Port
A switch port configured to carry traffic from multiple VLANs simultaneously between network devices using 802.1Q tagging.

U

UDP (User Datagram Protocol)
A connectionless Layer 4 protocol that offers fast, low-overhead delivery without guaranteed reliability or ordering.

V

VLAN (Virtual Local Area Network)
A logical grouping of devices on the same or different physical switches into a separate broadcast domain.
VPN (Virtual Private Network)
An encrypted tunnel over a public network that allows remote users or sites to communicate securely as if on a private network.

W

WAN (Wide Area Network)
A network spanning large geographic distances, connecting multiple LANs via ISP infrastructure, leased lines, or the internet.
Wi-Fi
Wireless LAN technology based on the IEEE 802.11 standards, allowing devices to connect to a network via radio waves.
